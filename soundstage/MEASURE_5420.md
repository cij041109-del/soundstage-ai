# 5420 강의실 실측 기록 시트

- 측정일: ____년 __월 __일  측정자: __________  도구: 줄자 / 레이저 거리측정기
- 단위는 모두 **m**, 소수점 둘째 자리(cm)까지 적는다.
- 측정이 끝나면 아래 대응표를 보고 `soundstage/rooms.json`의 `"5420"` 항목에 값을 옮겨 적고,
  `"measured": true`로 바꾼 뒤 `python soundstage/check_room.py`로 확인한다.

> **이번 범위에서 제외:** 벽·바닥·천장의 흡음률 등 재질 측정은 하지 않는다.
> `wall_absorption`(현재 0.3)은 그대로 둔다.

---

## 1. 좌표 기준

원점은 **앞벽(칠판·교탁 쪽)·왼쪽 벽·바닥이 만나는 모서리**이다.
뒤쪽 벽을 등지고 칠판을 바라볼 때 왼쪽 앞 모서리 바닥이 원점이다.

- **x**: 원점에서 **오른쪽**으로 (앞벽을 따라)
- **y**: 원점에서 **뒤쪽**으로 (왼쪽 벽을 따라, 교실 뒤편 방향)
- **z**: 바닥에서 **위쪽**으로

```
위에서 내려다본 그림 (z축은 화면 밖으로 나오는 방향 = 위쪽)

        앞벽 (칠판·교탁)
  (0,0) ●──────────────────────────► x (오른쪽, 가로)
        │      [  교탁  ]           │
        │                           │
  왼쪽  │   ○      ○      ○  ← 1행 (앞줄)
   벽   │   ↑첫 좌석                 │
        │   ○      ○      ○  ← 2행  │
        │                           │
        │   ○      ○      ○         │
        ▼                           │
        y (뒤쪽, 세로)      뒷벽
```

- 각 위치는 "왼쪽 벽에서 몇 m(x), 앞벽에서 몇 m(y)"로 잰다.
- 물체(교탁 등)는 **바닥에 그린 직사각형**으로 보고 x·y의 최소/최대를 잰다.

## 2. 측정 방법 (짧게)

1. **방 치수**: 바닥에서 왼쪽 벽→오른쪽 벽(가로), 앞벽→뒷벽(세로)을 2곳 이상 재서 평균. 천장 높이는 바닥→천장(천장 타일 기준)을 2곳 이상.
2. **교탁·칠판**: 왼쪽 벽에서 물체 왼쪽 끝/오른쪽 끝까지(x), 앞벽에서 물체 앞/뒤 끝까지(y).
3. **첫 좌석**: 앞줄 가장 왼쪽 자리의 **의자 가운데(사람이 앉는 위치)**를 기준으로 x, y를 잰다.
4. **열·행 간격**: 같은 줄에서 옆자리 의자 가운데끼리(열 간격), 앞뒤 줄 의자 가운데끼리(행 간격). 여러 자리를 재서 평균.
   - 자리가 고르지 않으면 "첫 자리 ~ 마지막 자리 거리 ÷ (개수 − 1)"로 구한다.
5. **귀 높이**: 앉은 사람 귀 높이. 특별한 이유가 없으면 1.2 m 그대로.
6. **문·창문**: 참고용. 어느 벽(앞/뒤/왼/오른)에 있는지와 시작·끝 위치만.

## 3. 기록 표

### 3-1. 방 치수

| 항목 | 1회 | 2회 | 평균 | rooms.json 항목 |
|---|---|---|---|---|
| 가로 (x, 왼쪽 벽 → 오른쪽 벽) | | | | `dimensions_m[0]` |
| 세로 (y, 앞벽 → 뒷벽) | | | | `dimensions_m[1]` |
| 천장 높이 (z, 바닥 → 천장) | | | | `dimensions_m[2]` |

### 3-2. 교탁·칠판 (스피커 설치 금지 구역)

| 물체 | x 최소 (왼쪽 끝) | x 최대 (오른쪽 끝) | y 최소 (앞 끝) | y 최대 (뒤 끝) | 높이 (참고) | 비고 |
|---|---|---|---|---|---|---|
| 교탁 | | | | | | |
| 칠판 / 스크린 | | | (벽면이면 0) | (벽면이면 0) | 아래 __ ~ 위 __ | |
| 기타 (프로젝터 등) | | | | | | |

→ 금지 구역 하나당 `forbidden_zones`에 `[x 최소, y 최소, x 최대, y 최대]` 한 줄.

### 3-3. 좌석 배치

| 항목 | 측정값 | rooms.json 항목 |
|---|---|---|
| 첫 좌석(앞줄 왼쪽) x | | `seating.first_seat_xy_m[0]` |
| 첫 좌석(앞줄 왼쪽) y | | `seating.first_seat_xy_m[1]` |
| 열 수 (한 줄에 몇 자리, x 방향) | | `seating.cols` |
| 행 수 (몇 줄, y 방향) | | `seating.rows` |
| 열 간격 (옆자리 사이, x 방향) | | `seating.col_spacing_m` |
| 행 간격 (앞뒤 줄 사이, y 방향) | | `seating.row_spacing_m` |
| 귀 높이 | 1.2 (기본) | `seating.ear_height_m` |

- 좌석이 많으면 모든 자리 대신 대표 자리(예: 3열 x 4행)만 골라 적어도 된다.
- 확인: 마지막 줄 y = 첫 좌석 y + (행 수 − 1) x 행 간격 이 세로보다 작아야 한다. (오른쪽 끝 x도 마찬가지)

### 3-4. 문·창문 (참고용, rooms.json에는 아직 넣지 않음)

| 종류 | 있는 벽 (앞/뒤/왼/오른) | 시작 위치 | 끝 위치 | 아래 높이 | 위 높이 | 비고 |
|---|---|---|---|---|---|---|
| 문 1 | | | | 0 | | |
| 문 2 | | | | 0 | | |
| 창문 1 | | | | | | |
| 창문 2 | | | | | | |

(앞/뒤 벽이면 위치는 x, 왼/오른 벽이면 위치는 y로 적는다.)

### 3-5. 스피커 설치 조건 (확인만)

| 항목 | 현재값 | 바꿀 값 (필요할 때만) | rooms.json 항목 |
|---|---|---|---|
| 스피커 설치 높이 | 2.5 | | `speaker_height_m` (천장 높이보다 작아야 함) |
| 벽과 최소 거리 | 0.5 | | `min_wall_distance_m` |

## 4. rooms.json 항목 대응표

| 측정 항목 | rooms.json 항목 | 예 (현재 임시값) |
|---|---|---|
| 가로, 세로, 천장 높이 | `"dimensions_m": [가로, 세로, 높이]` | `[10.0, 8.0, 3.0]` |
| 교탁·칠판 등 금지 구역 | `"forbidden_zones": [[x최소, y최소, x최대, y최대], ...]` | `[[4.0, 0.0, 6.0, 2.0]]` |
| 첫 좌석 위치 | `"seating": {"first_seat_xy_m": [x, y]}` | `[1.0, 2.0]` |
| 열 수 / 행 수 | `"seating": {"cols": .., "rows": ..}` | `3`, `4` |
| 열 간격 / 행 간격 | `"seating": {"col_spacing_m": .., "row_spacing_m": ..}` | `4.0`, `1.6666666666666667` |
| 귀 높이 | `"seating": {"ear_height_m": ..}` | `1.2` |
| 스피커 설치 높이 | `"speaker_height_m"` | `2.5` |
| 벽과 최소 거리 | `"min_wall_distance_m"` | `0.5` |
| 실측 완료 표시 | `"measured": true` | 지금은 `false` |
| 메모 | `"note"` (측정일·측정자 등) | `"임시값, 실측 후 교체 ..."` |
| 문·창문 | (아직 없음, 이 시트에만 기록) | |
| 벽 흡음률 | `"wall_absorption"` — **이번에는 측정하지 않음, 그대로 둠** | `0.3` |

참고:
- `seating`이 있으면 청취 지점은 seating으로 자동 생성되고, `listening_points`는 쓰이지 않는다.
  (실측값을 seating에 적은 뒤 `listening_points`는 지워도 된다)
- 값을 고친 뒤 `python soundstage/check_room.py` 를 돌리면 잘못된 값(방 밖 좌석, 방 밖 금지 구역 등)을
  한국어로 알려 주고, 문제가 없으면 추천 위치와 개선율까지 계산해 보여 준다.
